# MESAFARTAI – Logística e Inteligência Assistiva no Combate à Fome

## Sobre o projeto

O MESAFARTAI é uma aplicação conversacional desenvolvida em Python com o objetivo de facilitar a doação e distribuição de alimentos que ainda estão próprios para consumo.

A proposta é utilizar Inteligência Artificial e Processamento de Linguagem Natural (NLU) para entender mensagens informais dos doadores, identificar informações importantes sobre os alimentos e auxiliar na busca por uma ONG próxima.

O projeto também utiliza Regex para extração de informações, SQLite3 para armazenamento dos dados e algoritmos de Machine Learning para auxiliar no processo de matchmaking logístico.

## Objetivo

Facilitar a comunicação entre pessoas ou estabelecimentos que possuem alimentos para doar e instituições que precisam desses alimentos.

O sistema deverá interpretar mensagens, identificar informações sobre as doações e auxiliar no direcionamento para uma ONG próxima.

## Problema

Muitos alimentos próprios para consumo são descartados por motivos como proximidade da validade, excesso de estoque ou pequenos problemas estéticos.

Ao mesmo tempo, ONGs, abrigos e cozinhas comunitárias enfrentam dificuldades para conseguir alimentos para pessoas em situação de vulnerabilidade.

O MESAFARTAI busca aproximar esses dois lados de maneira mais rápida e organizada.

## ODS 2

O projeto está alinhado à ODS 2 da ONU, relacionada ao combate à fome, segurança alimentar e agricultura sustentável.
